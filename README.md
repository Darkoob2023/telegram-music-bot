# 🎵 Telegram Music Bot

A Telegram bot for managing and playing your personal music archive with lyrics, cover art, song recognition, and smart recommendations.

---

## ✨ Features

- 🎵 Save and play songs by artist
- 📝 Online lyrics via LRCLIB
- 🖼 Album art via iTunes
- ℹ️ Song details via Last.fm
- ▶️ 30-second preview via Deezer
- 🎯 Smart recommendations based on listening history
- 🔍 Song recognition from audio/video clips (Shazam-like)
- 📊 Listening statistics

---

## 📋 Commands

| Command | Description |
|---|---|
| `/start` | Start the bot |
| `/play` | Browse and play songs by artist |
| `/random` | Play a random song |
| `/search` | Search your archive |
| `/list` | List all artists |
| `/identify` | Recognize a song from a clip |
| `/top` | Most played songs |
| `/stats` | Full archive statistics |
| `/delete` | Delete songs |
| `/help` | Show help |
| `/about` | About the bot |
